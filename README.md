# Altis Labs

React + TypeScript frontend, scaffolded with Vite. A responsive company page for Altis Labs, featuring our products, client services, and CEO Assistant.

## Local development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

## Project details

- Intended domain: https://altislabs.praispranav.com
- Business and support email: praispranav@gmail.com
- Product configuration: `src/config/site.ts`
- ClinicQ: https://clinicq.fit
- WhereAmI: coming soon; AI-based study app, detailed description pending.
- IAmCEO: coming soon; CEO Assistant for daily business operations.

The domain has been recorded only. DNS and deployment are not configured.

Early-access and project links open the visitor’s email app with a draft addressed to praispranav@gmail.com. There is no backend or automatic waitlist enrollment. CEO Assistant examples are illustrative product concepts, not a live assistant.
